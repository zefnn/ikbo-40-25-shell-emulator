# Эмулятор командной строки (ИКБО-40-25, Вариант №10)

Учебный проект по дисциплине «Конфигурационное управление».
Эмулятор командной строки UNIX-подобной ОС с графическим
интерфейсом и виртуальной файловой системой (VFS). Разработка
ведётся поэтапно; текущее состояние соответствует **Этапу 1
(REPL)**.

## Общее описание

Приложение — минимальный REPL-прототип с GUI на Tkinter:
пользователь вводит команды в поле ввода, эмулятор разбирает
строку на имя команды и аргументы (с поддержкой аргументов в
кавычках) и выводит результат в область прокрутки, имитируя
диалог в терминале. Работа с файловой системой, конфигурацией и
логированием появится на следующих этапах.

## Функции и настройки

Реализовано на Этапе 1:

- **GUI-окно** (Tkinter) с областью вывода (scrollback) и полем
  ввода. Заголовок окна содержит имя VFS (пока используется
  заглушка — реальная загрузка VFS появится на Этапе 3).
- **Парсер команд** (`shellemu.parser`) — собственная реализация
  на основе посимвольного разбора строки (без сторонних библиотек
  парсинга), корректно обрабатывающая аргументы в одинарных и
  двойных кавычках.
- **Команды-заглушки** `ls`, `cd` — выводят своё имя и разобранные
  аргументы, не изменяя никакого состояния.
- **Команда `exit`** — закрывает окно эмулятора.
- **Обработка ошибок**:
  - неизвестная команда → `<имя>: command not found`;
  - некорректный синтаксис аргументов (например, незакрытая
    кавычка) → `parse error: <причина>`.

Настраиваемых параметров на этом этапе нет — командная строка и
YAML-конфигурация появятся на Этапе 2.

## Сборка и тесты

Требования: Python 3.10+ (используется стандартный модуль
`tkinter`), `pytest` для тестов.

```bash
pip install pytest
```

Запуск эмулятора:

```bash
./run.sh
```

Запуск тестов:

```bash
pytest
```

## Примеры использования

После запуска в окне эмулятора отображается приглашение вида
`VFS:~$`. Пример сеанса:

```
VFS:~$ ls -la /tmp
[stub] command='ls' args=['-la', '/tmp']
VFS:~$ cd "My Documents"
[stub] command='cd' args=['My Documents']
VFS:~$ foo bar
foo: command not found
VFS:~$ ls "unterminated
parse error: missing closing quote: "
VFS:~$ exit
```

Второй пример показывает, что аргумент в кавычках (`"My
Documents"`) распознаётся как один токен, а не как два. Реальная
логика `ls`/`cd` и остальные команды появятся на Этапе 4 — на
Этапе 1 это заглушки для проверки парсера и цикла REPL.
